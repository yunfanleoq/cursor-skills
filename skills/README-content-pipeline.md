# 公众号内容技能栈

基于 [Skill Hub 中国](https://www.skill-cn.com) 常用技能（humanizer-zh、brainstorming、agent-browser）与实战经验整理。

## 技能一览

| 技能 | 目录 | 说明 |
|------|------|------|
| content-capture | `content-capture/` | 采集：Obsidian 剪藏、微信 Playwright、浏览器 |
| article-brainstorm | `article-brainstorm/` | 动笔前：读者、角度、大纲 |
| humanizer-zh | `humanizer-zh/` | 去 AI 味润色 |
| wechat-article-publish | `wechat-article-publish/` | 配图 + 远程推草稿 |

## 标准流水线

1. 有链接 → `content-capture`
2. 新题 → `article-brainstorm` 确认写法
3. 写 Markdown 初稿
4. **`humanizer-zh` 润色**（不可跳过）
5. `wechat-article-publish`：`--thumb` + `--author "RPA老刘"` + SCP 配图
