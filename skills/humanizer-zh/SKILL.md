# Humanizer-zh：去除 AI 写作痕迹

> 参考：[Skill Hub - humanizer-zh](https://www.skill-cn.com/skill/32) · [op7418/Humanizer-zh](https://github.com/op7418/Humanizer-zh)

## 何时使用

- 用户说「去 AI 味」「太死板」「不像人写的」「润色一下」
- **公众号 / 朋友圈文案定稿前**（配合 `wechat-article-publish`）
- 审阅 AI 生成的科普稿、营销文、摘要

## 工作流程

1. **扫描** — 对照下方「公众号高频 AI 痕迹」和 [reference-patterns.md](reference-patterns.md)
2. **重写** — 删填充、破公式、变节奏；保留事实与数字
3. **注入人味** — 有观点、有具体细节、长短句交错
4. **评分** — 五维各 /10（直接性、节奏、信任度、真实性、精炼度），总分 ≥ 40 再交付

## 核心五原则

1. **删填充** — 去掉「值得注意的是」「综上所述」「很多人……却容易忽略」式铺垫
2. **破公式** — 不要「不仅……而且……」、不要段段「——」、不要每节蓝底标题+三段正文
3. **变节奏** — 2～3 行一段；一句短、一句长；列举 2 项或 4 项，少用整齐三项
4. **信任读者** — 直接说事，少手把手引导、少「这么说吧」
5. **删金句** — 听起来像海报标语的句子，改成口语或具体事实

## 公众号专用禁忌（RPA老刘 账号）

**禁止或慎用：**

| 类型 | 示例 |
|------|------|
| 公文连接词 | 此外、然而、因此、综上所述、值得注意的是 |
| 赋能体 | 赋能、打造、助力、一站式、深度融合 |
| 空洞升华 | 万事顺遂、所念皆如愿、一路坦途（堆砌时） |
| 模板破折号 | 「年6、月6、日6、星期6——四个6齐聚」可保留一次，正文勿反复 |
| 说教口吻 | 「很多人只记得……却容易忽略第四个」→ 改成「还有个细节：星期也是 6」 |
| 列表教科书 | 四个维度逐条 +「← 关键一维」→ 改成叙述或只留一行提示 |
| 过度 emoji | 全文不超过 1～2 个，忌 🍀✨ 结尾套餐 |

**提倡：**

- 像跟朋友唠嗑：短句、口语、偶尔反问
- 数字要实在：110 年、1916、2136 留着，别换成「很久很久以前」
- 有立场：「我查了下日历，这种日子确实少见」
- 段落参差：别每段都是「标题 + 列表 + 总结」

## 改写示例（公众号场景）

**AI 味：**

> 很多人只记得年月日三个「6」，却容易忽略第四个。四个「6」同时落在星期六，这才构成「四六大顺」。少一个，都不算。

**人味：**

> 2026、6 月、6 号，这三个 6 好记。容易漏掉的是：今天周六，中文里也叫「星期6」。四个凑齐，老辈人会说六六大顺——这种日子，上次 1916 年，下次 2136 年，中间隔 110 年。

## 输出格式

1. 给出**改写后全文**（可直接替换 Markdown）
2. 可选：3～5 条修改说明
3. 五维评分；低于 35 分继续改一轮
